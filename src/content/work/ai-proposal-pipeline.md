A Claude agent backed by Python scripts that turns a project brief into an internally reviewed commercial proposal. It fingerprints every input with SHA-256, recomputes all geometry from raw parameters, generates parametric drawings, assembles the PDF, and runs a release check that blocks stale deadlines, unconfirmed pricing, and images that don't trace back to the right client.
